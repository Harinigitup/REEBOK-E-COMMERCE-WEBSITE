# Nike Ecommerce Website - Frontend Project

## Project Overview
A fully responsive Nike ecommerce website built with HTML, CSS, and JavaScript. Features a modern design with product showcase, shopping cart functionality, and payment integration.

## Features Completed ✅

### 🎨 Design & Layout
- **Responsive Design**: Mobile-first approach with breakpoints at 480px
- **Modern UI**: Clean, professional Nike-inspired design
- **Interactive Elements**: Hover effects, smooth transitions, and animations

### 🛍️ Ecommerce Functionality
- **Product Showcase**: 5 different Nike shoe models with detailed views
- **Product Selection**: Color and size selection for each product
- **Shopping Cart**: Add to cart functionality with visual feedback
- **Checkout Process**: Complete payment form with validation
- **Search Feature**: Real-time product search functionality

### 📱 Responsive Features
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Responsive Images**: Optimized images for all screen sizes
- **Touch-Friendly**: Large buttons and interactive elements for touch devices

### 🔍 Search & Filter
- **Search Bar**: Real-time product search with keyboard support
- **Product Filtering**: Filter by product name
- **Instant Results**: Immediate feedback on search queries

### 📧 Newsletter Subscription
- **Email Validation**: Client-side email format validation
- **Subscription Form**: Clean newsletter signup in footer

- Chrome (latest)

## How to Use
1. Open `index.html` in any modern web browser
2. Browse products using the navigation or search
3. Select colors and sizes for products
4. Add items to cart and proceed to checkout
5. Fill in payment details to complete purchase
